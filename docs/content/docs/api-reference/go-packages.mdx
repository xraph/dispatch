This is a reference map of every package in the module, what it exports, and when you'd use it.

## dispatch (root)

**Import:** `github.com/xraph/dispatch`

| Export | Type | Purpose |
|--------|------|---------|
| `Dispatcher` | struct | Core dispatcher: store, worker pool, queue routing |
| `New(opts...)` | func | Constructor. You need `WithStore`, or `engine.Build` fails with `ErrNoStore` |
| `Config` | struct | Runtime configuration (concurrency, queues, intervals) |
| `DefaultConfig()` | func | Returns sensible defaults |
| `Option` | type | Functional option type |
| `WithStore(s)` | func | Set the backing store |
| `WithLogger(l)` | func | Set the go-utils `log.Logger` |
| `WithConcurrency(n)` | func | Global worker concurrency |
| `WithQueues(qs)` | func | Queues the workers poll |
| `WithPollInterval`, `WithMaxPollInterval`, `WithHeartbeatInterval`, `WithStaleJobThreshold`, `WithWorkerStoreCallTimeout`, `WithCron*` | func | Worker and cron tuning |
| `Storer` | interface | Composite store interface the dispatcher needs |
| `ErrJobNotFound`, `ErrRunNotFound`, `ErrCronNotFound`, `ErrDLQNotFound`, `ErrWorkflowNotFound`, `ErrEventNotFound` | errors | Not-found sentinels |
| `ErrLeadershipLost` | error | Returned when a leader-only operation loses the lease |
| `ErrInvalidState`, `ErrDLQAlreadyReplayed`, `ErrDuplicateCron` | errors | State and conflict errors |
| `ErrPermanent` | error | Wrap it in a handler error to skip the remaining retries |
| `ErrNoStore` | error | Returned by `engine.Build` (and `Start`) when there's no store |

## engine

**Import:** `github.com/xraph/dispatch/engine`

The engine package is the import-cycle breaker. It composes all subsystems and is the primary surface for application code.

| Export | Type | Purpose |
|--------|------|---------|
| `Engine` | struct | Assembled runtime: dispatcher + extensions + middleware + workers |
| `Build(d, opts...)` | func | Build an engine from a `*dispatch.Dispatcher`; returns `(*Engine, error)` |
| `Register[T](eng, def)` | func | Register a `job.Definition[T]` with the engine |
| `RegisterChecked[T](eng, def)` | func | Register and validate artifact inputs and execution policy |
| `RegisterAll(eng, defs...)` | func | Validate and register several `job.Registrable` definitions |
| `Enqueue[T](ctx, eng, name, payload, opts...)` | func | Enqueue a job by name; returns `(*job.Job, error)` |
| `Bind(name, ref)` | func | A `job.Option` that binds an artifact to a declared input |
| `RegisterWorkflow[T](eng, def)` | func | Register a `workflow.Definition[T]` |
| `StartWorkflow[T](ctx, eng, name, input)` | func | Start a workflow by name; returns `(*workflow.Run, error)` |
| `RegisterCron[T](ctx, eng, def)` | func | Register a `*cron.Definition[T]` (idempotent by name) |
| `Option` | type | Engine option type |
| `WithMiddleware(m)` | func | Add a middleware to the chain |
| `WithExtension(x)` | func | Register an `ext.Extension` |
| `WithBackoff(s)` | func | Override the retry backoff strategy |
| `WithQueueConfig(cfgs...)` | func | Per-queue concurrency and rate limit settings |
| `WithTracerProvider(tp)` | func | OpenTelemetry tracer provider for the tracing middleware |
| `WithMetricFactory(f)` | func | go-utils metric factory (the Forge extension passes the app's) |
| `WithDurableWorkflows(opts)` | func | Turn on the durable workflow runtime |
| `WithStreamBroker(opts...)` | func | Turn on the stream broker DWP needs |
| `WithArtifacts(svc, cache)`, `WithExecutor(e)`, `WithScratchRoot(dir)` | func | Artifact plane and execution isolation |
| `WithResourceManager`, `WithWorkerCapacity`, `WithWorkerCustomKeys`, `WithResourceDefaults`, `WithEstimator` | func | Resource-aware admission |

`*Engine` methods cover operator actions (`CancelJob`, `RetryJob`, `ReplayDLQ`, `ReplayAllDLQ`, `PurgeDLQ`, `DeleteDLQ`, `EnableCron`, `DisableCron`, `DeleteCron`, `TriggerCron`, `ReplayWorkflowFrom`), lifecycle (`Start`, `Stop`, `Health`) and access to the subsystems (`Dispatcher`, `DLQService`, `EventBus`, `CronStore`, `ClusterStore`, `StreamBroker`, `Registry`).

## workflow

**Import:** `github.com/xraph/dispatch/workflow`

| Export | Type | Purpose |
|--------|------|---------|
| `Definition[T]` | struct | Typed workflow definition |
| `NewWorkflow[T](name, fn)` | func | Create a workflow definition |
| `Run` | struct | Persisted workflow run entity |
| `RunState` | string | Run state enum: `running`, `completed`, `failed` |
| `Workflow` | struct | Runtime context passed to the workflow function |
| `Registry` | struct | Holds all registered workflow definitions |
| `ListOpts` | struct | Pagination and filter options for runs |

`Workflow` methods used inside a workflow function:

| Method | Purpose |
|--------|---------|
| `Step(name, fn)` | Execute a step; replay checkpoint on re-run |
| `StepWithCompensation(name, exec, compensate)` | Execute a step with saga compensation |
| `Parallel(groupName, fns...)` | Execute steps in parallel, each checkpointed |
| `WaitForEvent(name, timeout)` | Block until a named event is published; `nil, nil` on timeout |
| `WaitForAll(names, timeout)`, `WaitForAny(names, timeout)`, `WaitForMatch(name, timeout, fn)` | Wait on several events, or filter by payload |
| `Sleep(name, duration)` | Durable sleep using a checkpoint |
| `RunCompensations()` | Manually run all registered compensations |

Package-level generic functions:

| Function | Purpose |
|----------|---------|
| `StepWithResult[T](wf, name, fn)` | Execute a step that returns a typed value |
| `StepWithResultAndCompensation[T](wf, name, exec, compensate)` | Typed step with compensation |
| `RunChild[T, R](wf, name, input)` | Run a child workflow and wait for its result |
| `SpawnChild[T](wf, name, input)` | Spawn a fire-and-forget child workflow |
| `FanOut[T, R](wf, name, inputs)` | Start one child workflow per input and collect the results |

## id

**Import:** `github.com/xraph/dispatch/id`

K-sortable (UUIDv7) TypeIDs. Every entity shares one `ID` struct; the per-entity names are type aliases of it, so the prefix is what tells them apart.

| Export | Purpose |
|--------|---------|
| `ID`, `JobID`, `RunID`, `WorkflowID`, `CronID`, `DLQID`, `EventID`, `WorkerID`, `CheckpointID`, `ArtifactID`, `UsageID` | The ID type and its aliases |
| `New(prefix)`, `NewJobID()`, `NewRunID()`, etc. | Generate a new ID |
| `Parse(s)`, `ParseWithPrefix(s, prefix)`, `ParseJobID(s)`, etc. | Parse a TypeID string, with prefix validation for the typed ones |
| `MustParse(s)`, `MustParseWithPrefix(s, prefix)` | Parse or panic |

Prefix constants:

| Constant | Prefix |
|----------|--------|
| `PrefixJob` | `job` |
| `PrefixWorkflow` | `wf` |
| `PrefixRun` | `wfrun` |
| `PrefixCheckpoint` | `ckpt` |
| `PrefixCron` | `cron` |
| `PrefixDLQ` | `dlq` |
| `PrefixEvent` | `evt` |
| `PrefixWorker` | `wkr` |
| `PrefixArtifact` | `art` |
| `PrefixUsage` | `use` |

## dwp

**Import:** `github.com/xraph/dispatch/dwp`

The Dispatch Wire Protocol package provides a frame-based protocol for remote clients to interact with the engine over WebSocket, SSE, or HTTP RPC. See [DWP Subsystem](/docs/subsystems/dwp) for details.

| Export | Type | Purpose |
|--------|------|---------|
| `Server` | struct | DWP server managing transports and connections |
| `NewServer(broker, handler, opts...)` | func | Create a DWP server |
| `Handler` | struct | Dispatches incoming DWP frames to engine methods |
| `NewHandler(eng, broker, logger, boundary...)` | func | Create a DWP handler; without a configured boundary every frame is denied |
| `Frame` | struct | Protocol frame envelope (`ID`, `Type`, `Method`, `Data`, etc.) |
| `FrameType` | string | Frame type enum: `request`, `response`, `event`, `error`, `ping`, `pong` |
| `Codec` | interface | Serialization codec (JSON, msgpack) |
| `Identity` | struct | Authenticated client identity (`Subject`, `AppID`, `OrgID`, `Scopes`) |
| `APIKeyEntry` | struct | API key configuration (`Token`, `Identity`) |
| `NewAPIKeyAuthenticator(entries...)` | func | Create a token-based authenticator |
| `Option` | type | Server option type |
| `WithAuth(auth)` | func | Set the authenticator |
| `WithSecurity(boundary)` | func | Set the authorization boundary |
| `WithCodec(c)`, `WithPath(p)`, `WithFederation(f)` | func | Codec, base path (`/dwp`) and federation |
| `WithLogger(l)` | func | Set the logger |

Scope constants (legacy vocabulary; the boundary authorizes requests, not scopes):

| Constant | Value | Description |
|----------|-------|-------------|

## store

**Import:** `github.com/xraph/dispatch/store`

| Export | Purpose |
|--------|---------|
| `Store` | Composite interface of the job, workflow, cron, DLQ, event, cluster and artifact stores (plus their listers), with `Migrate`, `Ping` and `Close` |

Backend packages:

| Package | Driver |
|---------|--------|
| `store/memory` | In-memory (`memory.New()`), for development and tests |
| `store/postgres` | PostgreSQL over a Grove database (`postgres.New(*grove.DB)`) |
| `store/sqlite` | SQLite over a Grove database (`sqlite.New(*grove.DB)`) |
| `store/mongo` | MongoDB over a Grove database (`mongo.New(*grove.DB)`) |
| `store/redis` | Redis over a Grove KV store (`redis.New(*kv.Store)`) |
| `store/storetest` | Conformance suites for store implementations |

Every backend satisfies `store.Store`. Only `store/memory` and `store/postgres` implement `durable.Store` for the durable workflow runtime.
