---
title: Relay Hook
description: Emit typed webhook events at every Dispatch lifecycle point using relay_hook.
---

The `relay_hook` package bridges Dispatch lifecycle events to [Relay](https://github.com/xraph/relay) for webhook delivery. When registered as a Dispatch extension, it emits a typed webhook event at every job, workflow and cron lifecycle point, and for every operator action.

## Setup

```go
import (
    "github.com/xraph/relay"
    "github.com/xraph/dispatch/relay_hook"
    "github.com/xraph/relay/store/memory"
)

// Create a Relay instance.
r, err := relay.New(relay.WithStore(memory.New()))
if err != nil {
    return err
}

// Register the event types Dispatch will emit.
if err := relay_hook.RegisterAll(ctx, r); err != nil {
    return err
}

// Create the hook extension.
hook := relay_hook.New(r)

// Register it with the engine.
eng, err := engine.Build(d,
    engine.WithExtension(hook),
)
```

## Emitted event types

| Event type | Lifecycle point |
|-----------|----------------|
| `dispatch.job.enqueued` | Job accepted into queue |
| `dispatch.job.started` | Worker begins execution |
| `dispatch.job.completed` | Job finishes successfully |
| `dispatch.job.failed` | Job fails terminally |
| `dispatch.job.retrying` | Job fails, scheduled for retry |
| `dispatch.job.dlq` | Job moved to DLQ |
| `dispatch.job.cancelled` | Job cancelled |
| `dispatch.workflow.started` | Workflow run begins |
| `dispatch.workflow.step_completed` | Workflow step completes |
| `dispatch.workflow.step_failed` | Workflow step fails |
| `dispatch.workflow.completed` | Workflow run completes |
| `dispatch.workflow.failed` | Workflow run fails |
| `dispatch.cron.fired` | Cron entry fires |

Operator actions get their own events: `dispatch.operator.job_cancelled`, `job_retried`, `dlq_replayed`, `dlq_deleted`, `dlq_purged`, `cron_enabled`, `cron_disabled`, `cron_deleted`, `cron_triggered` and `workflow_replayed`, all under the `dispatch.operator.` prefix. There's no shutdown event.

## Filtering events

Restrict which events are emitted:

```go
hook := relay_hook.New(r,
    relay_hook.WithEvents(
        relay_hook.EventJobCompleted,
        relay_hook.EventJobFailed,
        relay_hook.EventJobDLQ,
        relay_hook.EventWorkflowFailed,
    ),
)
```

## Event payload

Each webhook event carries a small JSON payload describing the entity. For example, `dispatch.job.completed` sends:

```json
{
  "job_id": "job_01h2xcejqtf2nbrexx3vqjhp41",
  "job_name": "send_email",
  "queue": "default",
  "scope_org_id": "org_01h455vb",
  "elapsed_ms": 142
}
```

`relay_hook.WithPayloadFunc(eventType, fn)` replaces the payload for one event type.

## Tenant routing

Webhook events are routed to Relay endpoints matching the job's `ScopeOrgID` as the `TenantID`. If `ScopeOrgID` is empty, the event goes out with an empty tenant ID.
